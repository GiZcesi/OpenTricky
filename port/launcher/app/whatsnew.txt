OpenTricky.exe (the launcher shows it without a network). The release zip
also has the block alone as whatsnew.txt beside OpenTricky.exe, which the

comment (both are kept identical when a release is made).
Format: port/launcher/app/ot_util.h.
Replace it with the new release's block when the release notes are written.
A "draft:" line (ignored by the launcher) marks a block that is not final:
